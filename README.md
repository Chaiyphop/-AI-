## วิธีใช้งานระบบ AI Auto

1. ดับเบิลคลิก `ระบบAIอัตโนมัติ\สร้างผลผลิตทั้งหมด.bat`
2. ระบบจะสแกนไฟล์ทั้งหมด → วิเคราะห์ข้อมูลจริง (เวอร์ชัน/ชั้น/สูตร/Agent ฯลฯ) → เขียนผลผลิตใหม่ทับไฟล์เดิม
3. เปิด `ระบบAIอัตโนมัติ\ผลผลิตอัตโนมัติ\index.html` เพื่อดูผลงานทั้งหมด

> แก้ไขไฟล์ต้นทางเมื่อไหร่ รันระบบใหม่ ผลผลิตจะอัปเดตตามอัตโนมัติ

## เนื้อหาหลักโดยสรุป

- **สถาปัตยกรรม 4 ชั้น:** Orchestrator (ร่างกาย) → Prometheus (สมอง) → Evolution (จิตวิญญาณ) → Sovereign Doctrine (เจตจำนง)
- **กลไกเรียนรู้ตัวเอง:** Self-Perception Axiom `C(S) = I(S,S)` + สูตร `learningRate = 0.1 × (1 + selfPerception)`
- **วิวัฒนาการ 4 ยุค:** The Collective → The Singularity → The Pantheon → The Weaver
- **คลังสูตร:** 62 สูตร (5 หมวด + 12 สัจพจน์)

## ⚠️ ข้อควรระวัง

- **ไฟล์สิทธิบัตร:** ข้อมูลส่วนตัวบางส่วนดูเป็นข้อมูลสมมติ และระบบยังไม่มี prototype จริง — อย่ายื่นสิทธิบัตรด้วยเอกสารนี้โดยตรง (ผิดกฎหมาย) ต้องสร้างของจริงก่อนแล้วยื่นผ่านทนายสิทธิบัตร
