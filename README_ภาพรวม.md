# Genesis Rx - Drug Extraction AI (MVP v0.1)

## Project Overview
Genesis Rx is an AI-powered computational drug discovery platform designed to perform in-silico screening and ranking of candidate molecules using advanced computational descriptors and machine learning models.

## Key Features
- Secure data ingestion from public sources
- Rule-based molecular screening
- Explainable ML model for candidate ranking
- Auditable human-in-the-loop review workflow

## Project Status
**Current Phase**: MVP Development (Weeks 0-12)

## Setup and Installation
### Prerequisites
- Python 3.9+
- Node.js 16+
- Poetry (dependency management)
- Docker (optional)

### Local Development
```bash
# Clone the repository
git clone https://github.com/your-org/genesis-rx.git
cd genesis-rx

# Install dependencies
poetry install
npm install

# Run development server
poetry run start
```
