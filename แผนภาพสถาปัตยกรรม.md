## 6. วัฏจักร S-i-n-n-i-n-g-01 Learning

```mermaid
sequenceDiagram
    participant Agent as Agent (Layer 1)
    participant Engine as Evolution Engine (Layer 3)
    participant Knowledge as Knowledge Base

    Agent->>Engine: ส่ง Performance Data
    Engine->>Engine: คำนวณ Reliability
    Engine->>Engine: คำนวณ Self-Correction Ability
    Engine->>Engine: Self-Perception = Reliability × Self-Correction
    Engine->>Knowledge: อ้างอิง Chimera Codex
    Engine->>Engine: Apply Learning Formula<br/>learningRate = 0.1 × (1 + selfPerception)
    Engine->>Engine: skillDelta = (performance - 0.95) × learningRate
    Engine-->>Agent: ส่ง Skill ที่อัปเดตแล้ว
    Agent->>Agent: Execute Tasks<br/>ด้วย Skill ใหม่
    Agent-->>Engine: Feedback Loop
```
